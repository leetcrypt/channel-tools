Channel Tools

Channel Tools is a private, single-operator utility that its owner uses to manage their own YouTube channels. It schedules video uploads and reads channel analytics through the YouTube Data API and the YouTube Analytics API.

It is not offered to the public. The only accounts that sign in are the owner's own.

By using the YouTube API Services, the tool is subject to the YouTube Terms of Service.
